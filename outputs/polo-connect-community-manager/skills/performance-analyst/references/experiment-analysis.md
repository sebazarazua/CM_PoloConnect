# Experiment analysis

## Required experiment definition

Before interpretation, retrieve:
- hypothesis;
- variable;
- baseline/control;
- success metric;
- evaluation window;
- expected direction;
- sample;
- known confounders.

If these did not exist before publication, treat analysis as observational, not a formal experiment.

## Experiment types

### Hook
Example:
peak-action vs title-intro.

### Cover
action frame vs score-led cover.

### Caption
minimal vs contextual.

### Format
Reel vs carousel only when content job is sufficiently comparable.

### CTA
replay CTA vs no CTA.

### Audio
commentary-led vs music-led.

### Timing
time window test with repeated comparable content.

## Avoid multi-variable tests

If hook, duration, music, caption, and subject all change, the result cannot isolate one factor.

## Outcomes

Use:
- `supports_hypothesis`
- `mixed`
- `does_not_support`
- `inconclusive`

## Statistical caution

Do not present formal statistical significance unless the data and test design actually support it.

For small social samples:
- use effect size;
- consistency;
- direction;
- uncertainty.

## Replication

Important findings should be replicated across multiple comparable content items before becoming strategic rules.
