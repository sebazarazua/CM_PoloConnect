# Baselines and normalization

## Why baselines matter

Social performance is highly skewed by:
- event importance;
- famous subjects;
- format;
- time;
- distribution;
- account growth.

Raw numbers can mislead.

## Baseline hierarchy

Preferred:

1. same objective + format + event class;
2. same format + pillar;
3. same format + recent account period;
4. account-wide recent baseline;
5. external benchmark.

## Baseline statistics

Prefer:
- median;
- percentile;
- interquartile range;
- robust multiples.

Mean can be distorted by viral outliers.

## Comparable event classes

Possible classes:
- routine match;
- semifinal/final;
- breaking announcement;
- player profile;
- horse story;
- explainer;
- evergreen;
- product/live promo.

Do not compare a Palermo final to a routine fixture without context.

## Performance multiple

Example:

`shares_per_reach_post / median_shares_per_reach_comparable`

Report as:
- 1.8× comparable median.

Do not imply universal quality.

## Percentiles

Useful when sample is large enough.

Example:
- 85th percentile among comparable Reels.

## Minimum sample

No universal minimum.

Confidence should increase with:
- more comparable content;
- stable definitions;
- repeated result;
- fewer confounders.

When sample is small, label conclusions provisional.

## Time windows

Use consistent windows when comparing.

Examples:
- 24h vs 24h;
- 72h vs 72h;
- 7d vs 7d.

Do not compare one post after 3 hours with another after 14 days.

## Account growth

For long historical periods, normalize where possible because follower base and account maturity change.
