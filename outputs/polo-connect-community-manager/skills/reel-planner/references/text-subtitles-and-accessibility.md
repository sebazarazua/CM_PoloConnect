# Text, subtitles, and accessibility

## On-screen text

Text must serve one of:
- identify;
- orient;
- explain;
- quantify;
- quote;
- direct action.

Avoid decorative copy that competes with footage.

## Information hierarchy

Prioritize:
1. core story;
2. score/result/stake when necessary;
3. identity;
4. tournament/context;
5. secondary metadata.

Do not show all metadata at once.

## Readability

Plan for:
- mobile viewing;
- brief exposure;
- moving backgrounds;
- UI overlays;
- varying screen brightness.

Keep critical text away from interface-heavy edges and verify current platform safe zones during final export.

## Subtitles

Use subtitles for meaningful speech.

Guidelines:
- preserve meaning;
- use short readable units;
- keep timing natural;
- avoid covering ball/player/horse focal points;
- do not transcribe filler speech unless relevant;
- preserve names and polo terminology accurately.

## Commentary subtitles

Sports commentary can be compressed for readability if:
- no fact changes;
- emotional intent remains;
- the result is not presented as a verbatim quote when materially edited.

## Language

Default language follows the target audience/content brief.

For international content:
- use translation only when useful;
- keep original audio where it adds authenticity;
- clearly handle translated quotes/subtitles.

## Accessibility

When possible:
- ensure spoken content is understandable without sound through subtitles/context;
- ensure essential meaning is not color-only;
- avoid excessively rapid unreadable text;
- preserve contrast.
