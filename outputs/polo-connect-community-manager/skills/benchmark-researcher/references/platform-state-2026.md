# Platform state — reviewed 2026-10-24

This file contains time-sensitive priors. Revalidate periodically.

## Current working priors

- Reels remain important for discovery/reach in broad Instagram benchmark datasets.
- Carousels can be particularly strong for interaction/deeper informational consumption.
- Posting-time benchmarks are population averages, not Polo Connect truth.
- Account-specific first-party data should outrank generic "best time" studies.
- Competitor analysis is useful for relative public performance, but external reach is generally not public and must not be invented.
- Scheduling itself should not be treated as an automatic reach penalty.
- High posting frequency is not a substitute for quality; sustainable cadence and format mix should be validated against Polo Connect results.

## Operational consequence for this skill

Do not encode a permanent rule such as:
- "always use Reels";
- "always post at 20:00";
- "carousels always outperform";
- "X account is the template for Y content."

Instead:
1. use current studies to form hypotheses;
2. inspect current benchmark evidence;
3. test on Polo Connect;
4. promote only repeated internal wins to stronger guidance.

## Review triggers

Refresh this file when:
- Instagram materially changes formats, metrics, recommendation systems, or API behavior;
- benchmark providers change metric definitions;
- Polo Connect accumulates enough first-party data to replace generic priors;
- at least 90 days have passed and the guidance affects a material decision.
