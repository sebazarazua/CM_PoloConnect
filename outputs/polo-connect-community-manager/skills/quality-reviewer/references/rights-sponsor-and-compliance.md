# Rights, sponsor, and compliance

## Required asset rights

For every media asset record:
- owner/source;
- usage status;
- permitted surface;
- territory/time limits when known;
- credit;
- restrictions.

## Rights states

Acceptable for publication when applicable:
- `owned`
- `licensed`
- `permission_confirmed`
- platform/library usage allowed for that route

Blocking:
- `rights_unknown`
- `restricted`
- expired permission
- incompatible usage scope

## Music

Check:
- source;
- permitted usage path;
- scheduler/API implications;
- commercial/account restrictions when relevant.

A track available in the native Instagram library is not automatically equivalent to a reusable licensed audio file for API publishing.

## Attribution

Check:
- photographer;
- videographer;
- agency;
- broadcaster;
- original reporting;
- quote source.

Do not strip required credit.

## Sponsor

Use only supplied obligations.

Check:
- correct logo/version;
- required wording;
- size/prominence if specified;
- placement;
- exclusivity conflicts;
- campaign period;
- disclosure.

## Legal/compliance

Do not invent legal rules.

When explicit legal review is required by the organization, absence of approval blocks publication.

## Trademarks

Use tournament/team/sponsor marks according to supplied rights/brand guidance.

Do not assume a public logo can be freely modified.
