# Layout and hierarchy

## First-read rule

At feed-scroll speed, the viewer should detect the primary story without reading all text.

## Hierarchy levels

### H1
One dominant message:
- winner/result;
- match;
- player;
- horse;
- statistic;
- announcement;
- quote.

### H2
Context needed to correctly interpret H1.

### H3
Supporting detail.

### H4
Metadata / optional utility.

Avoid more simultaneous levels than necessary.

## Composition models

These are mechanisms, not fixed templates.

### Hero-led
Large authentic photo; compact information block.

### Data-led
Dominant number/score; supporting photo/context.

### Split
Two subjects/teams/data groups with deliberate comparison.

### Editorial
Photo + headline + metadata, magazine-like but mobile-first.

### Minimal
One visual + one line when content genuinely supports simplicity.

### Layered
Photo/background + modular information cards.

### Sequential
Designed for carousel progression.

## Negative space

Negative space should:
- improve focus;
- protect readability;
- enable crop resilience.

Do not create empty space merely to appear premium.

## Alignment

Use consistent alignment logic within a piece.

Intentional asymmetry is valid.

Random misalignment is not.

## Logo

Place where visible but subordinate unless the brand itself is the story.

## Grid thumbnail

Ensure:
- main subject remains visible;
- headline/result remains legible or safely dispensable;
- edge elements do not become awkward in crop.

Exact grid behavior is time-sensitive; verify current preview.
