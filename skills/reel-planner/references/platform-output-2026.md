# Platform output — reviewed 2026-10-24

This file contains time-sensitive delivery guidance. Verify current Meta/Instagram requirements before export or automated publishing.

## Working assumptions

- Reels are designed primarily for vertical mobile viewing.
- 9:16 should be treated as the default creative canvas unless the delivery path requires otherwise.
- Critical text, scores, faces, horses, and ball/action should not sit under common interface overlays or at extreme edges.
- Cover crops can display differently across profile/grid/feed surfaces; choose a central resilient focal point.
- Compression, codec, file-size, frame-rate, and duration constraints can change across publishing methods and APIs.

## Durable planning rule

Do not embed fragile platform limits into the narrative plan.

The plan should specify:
- vertical framing intent;
- target duration based on story;
- safe placement intent;
- cover/crop intent;
- audio/subtitle requirements.

The final editor/publishing layer must verify current technical specifications before export.

## Duration

Do not target the maximum allowed Reel duration by default.

Use the shortest duration that preserves:
- sporting comprehension;
- emotional payoff;
- required context.

## Safe zones

Because Instagram UI treatment changes, final visual QA should inspect the actual current placement/publishing preview rather than relying solely on old pixel diagrams.

## Export QA

Before publishing verify:
- current supported container/codec;
- resolution/aspect;
- audio track;
- file size;
- duration;
- cover;
- subtitles;
- current Meta/API constraints;
- rights and music availability.

## Automated publishing

If publishing via Meta API or third-party scheduler, validate the requirements of that exact route. A file accepted by the Instagram app may not have identical API constraints.
