# Platform adaptation — reviewed 2026-10-24

This file contains time-sensitive working guidance.

## Instagram feed

Caption:
- front-load relevance;
- avoid relying on users expanding the caption to understand the central fact;
- use line breaks for readability.

Graphic copy:
- keep primary information in the visual when the content requires immediate utility.

## Reels

Caption should add context/consequence rather than describe the video.

Overlay copy:
- minimal;
- readable;
- timed to action;
- source-of-truth facts only.

## Carousels

Caption should frame or deepen the carousel, not reprint every slide.

Per-slide text is part of the design system, not a long-form article by default.

## Stories

Copy should be extremely scannable.

Use:
- one primary message per frame;
- explicit viewing/time utility when relevant;
- interactive stickers only when interaction serves the content.

## Hashtags

Do not hardcode a preferred count.

Instagram discovery behavior changes and hashtags should be tested against Polo Connect first-party data.

## Caption technical constraints

Exact character limits, mention behavior, hashtag handling, and API constraints may vary by surface and publishing route.

The publishing layer must verify current platform/API requirements before submission.

## Accessibility

When the publishing route supports alt text, the copy package may provide a factual alt-text draft, but final publication must ensure it matches the rendered asset.
