# Anti-AI language

## Purpose

Remove patterns commonly associated with generic AI and low-quality marketing copy.

These are warning signals, not banned phrases in all contexts.

## High-risk patterns

### Inflated abstraction
- "una experiencia única"
- "un momento inolvidable"
- "una jornada llena de emoción"
- "la pasión se hizo presente"
- "el polo vibró como nunca"

Rewrite with the actual event.

### Generic superlatives
- incredible
- epic
- legendary
- historic
- unforgettable
- spectacular

Use only when evidence/context genuinely supports them.

### False contrast
- "No es solo un partido, es..."
- "Más que un deporte..."
- "No se trata solo de..."

Usually delete.

### Formulaic triads
Repeated:
- "pasión, tradición y excelencia"
- "velocidad, precisión y emoción"

Use specific observations instead.

### Synthetic suspense
- "No vas a creer..."
- "Esperá hasta el final"
- "¿El resultado? Increíble."

Avoid.

### Generic community bait
- "¿Qué opinás?"
- "Te leemos"
- "¿Quién gana?"
- "Etiquetá a..."

Use only when the question itself has editorial value.

### Meta-marketing language
- "contenido imperdible"
- "una propuesta pensada para vos"
- "seguimos acercándote..."
- "desde Polo Connect queremos..."

Lead with the sport, not the brand speaking about itself.

### AI rhythm
Warning signs:
- every sentence same length;
- every paragraph ends in a CTA;
- repeated colon-led lists;
- repeated em-dash explanatory clauses;
- overly balanced sentence structures;
- unnecessary summary sentence.

## Rewrite method

Replace abstraction with:
- fact;
- image;
- consequence;
- quote;
- precise detail.

Instead of:
"Una final cargada de emoción."

Use:
"Se definió en el último chukker."

Instead of:
"Un talento que sigue haciendo historia."

Use:
"Marcó 8 goles y terminó como máximo anotador de la final."

Only if verified.
