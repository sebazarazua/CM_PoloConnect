# Learning system

## Purpose

Turn performance evidence into durable Polo Connect knowledge.

## Maturity stages

### `external_hypothesis`
Derived from benchmarks/platform research.

Not yet proven for Polo Connect.

### `internal_observation`
Observed once or in a small sample.

Useful for next test.

### `repeated_internal_signal`
Observed multiple times in comparable conditions.

Can influence planning with caution.

### `validated_internal_pattern`
Repeated, reasonably controlled/normalized evidence.

Should meaningfully influence future strategy.

### `strategic_rule_candidate`
Strong enough to become a default unless future evidence changes.

Still not an eternal rule.

## Learning record

Store:
- learning ID;
- statement;
- mechanism;
- evidence IDs;
- content scope;
- sample;
- baseline;
- effect;
- confidence;
- confounders;
- maturity;
- decision;
- next test;
- review date.

## Promotion rules

Promote only when:
- evidence repeats;
- metric definitions are stable;
- comparison set is valid;
- confounders are understood;
- effect is meaningful;
- production cost is acceptable.

## Demotion

Demote when:
- new evidence contradicts;
- platform definition changes;
- audience behavior shifts;
- fatigue appears;
- strategy changes.

## Examples

Weak:
"Reels work best."

Better:
"Decisive-match Reels opening on peak action have repeatedly produced higher shares per reach than comparable title-intro Reels."

## Scope

Every learning must define scope.

A pattern can be valid for:
- finals;
- result content;
- horse stories;
- explainers;
- Stories;

without being valid globally.
