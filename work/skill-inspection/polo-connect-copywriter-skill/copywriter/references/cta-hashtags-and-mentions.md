# CTA, hashtags, and mentions

## CTA

Use only when the action is valuable.

### Strong
- watch live;
- watch replay;
- see stats;
- save a useful schedule;
- answer a real debate/prediction;
- continue to the next event/content.

### Weak
- like;
- comment;
- share;
- tag a friend

when included only as engagement bait.

## Product CTA

Tie directly to value.

Good:
"El replay completo ya está disponible en Polo Connect."

Weak:
"Descargá Polo Connect y descubrí todo lo que tenemos para vos."

## Hashtags

Use a small, relevant set only when useful.

Potential roles:
- tournament;
- branded;
- campaign;
- discoverability.

Avoid:
- dozens of generic tags;
- irrelevant trending tags;
- duplicates;
- tags with no relationship to content.

Platform hashtag behavior changes; review first-party performance rather than treating hashtag count as a fixed rule.

## Mentions

Use for:
- official participant;
- team;
- organizer;
- partner;
- sponsor;
- credited source.

Verify exact handle before final publication.

Do not infer handles from names.
