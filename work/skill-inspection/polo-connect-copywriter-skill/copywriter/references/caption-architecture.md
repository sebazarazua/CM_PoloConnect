# Caption architecture

## Principle

A caption should do work that the asset does not already do.

## Common structures

### Result
1. outcome/consequence;
2. one useful detail;
3. next event/context;
4. optional CTA.

### Highlight
1. name the moment or stakes;
2. brief context;
3. optional replay/live utility.

Do not narrate visible action line by line.

### Preview
1. why match matters;
2. practical schedule;
3. one storyline;
4. viewing CTA.

### Data
1. insight;
2. supporting number;
3. comparison/context;
4. optional source/date.

### Human
1. human detail/quote;
2. context;
3. consequence or relevance.

### Explainer
1. answer;
2. simple explanation;
3. example;
4. useful takeaway.

### Breaking
1. verified fact;
2. essential context;
3. what is still unknown when relevant.

## Length

No universal target.

Use:
- minimal caption when the visual carries the story;
- longer caption when context genuinely adds value.

Do not pad to an imagined ideal length.

## First line

Should work in preview.

Avoid:
- repeating the exact headline;
- vague tease;
- branding intro.

## Line breaks

Use for readability, not decorative rhythm.

Avoid putting every sentence on its own line.

## CTA placement

Usually final, but may appear earlier for urgent viewing utility.

Example:
"En vivo ahora en Polo Connect."
