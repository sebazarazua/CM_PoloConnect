# Transfer and originality

## Objective

Use external content to improve Polo Connect's creative decisions while maintaining an independent identity.

## Mechanism abstraction

Translate a reference through four steps:

1. **Surface** — what the post literally looks/sounds like.
2. **Mechanism** — what communication problem the choice solves.
3. **Constraint** — what made it work in that context.
4. **Transfer** — an original Polo Connect execution solving the same class of problem.

Example:

Surface:
Large score, player photo, compact header.

Mechanism:
Outcome is the audience's highest-priority information; player image carries emotion.

Constraint:
Viewer already knows the tournament context.

Transfer:
For a Polo Connect final-result asset, make the result dominant, use licensed match photography as the emotional focal point, and place tournament metadata in a subordinate layer using Polo Connect's own type/color system.

## Originality rules

Do not:
- trace layouts;
- reproduce a distinctive arrangement with cosmetic color changes;
- reuse slogans/headlines;
- clone another brand's motion package;
- imitate proprietary typography treatment;
- remove/cover watermarks;
- reuse unlicensed media;
- reproduce a sequence shot-for-shot.

Prefer:
- at least two independent reference mechanisms for significant creative directions;
- first-principles redesign;
- Polo Connect-owned footage, photography, statistics, and editorial voice;
- reusable Polo Connect design tokens/templates once defined.

## Similarity check

Before recommending a direction, ask:

1. Would the concept still make sense if the reference brand name disappeared?
2. Can the principle be described without mentioning the source account?
3. Is the final execution based on Polo Connect assets and identity?
4. Would a viewer confuse the output with the reference brand?
5. Are we borrowing a communication mechanism or a recognizable creative expression?

If answers 2 or 3 are no, or 4 is yes, redesign.

## Brand learning loop

External benchmarks are scaffolding.

As Polo Connect accumulates evidence:
- store its own successful patterns;
- compare experiments against internal baselines;
- promote validated internal mechanisms;
- reduce dependence on external references.

When external convention conflicts with repeated Polo Connect evidence, prefer Polo Connect evidence unless there is a strategic reason to retest.
