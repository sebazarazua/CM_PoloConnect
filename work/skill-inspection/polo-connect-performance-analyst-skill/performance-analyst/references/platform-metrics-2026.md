# Platform metrics — reviewed 2026-10-24

This file is time-sensitive.

## Metricool / Instagram working state

Current Metricool documentation indicates that owned Instagram analytics can include:
- organic reach;
- views;
- interactions;
- saves/shares among owned-account interactions when available;
- Story metrics such as forward taps and exits;
- Reel/post breakdowns.

Metricool notes that owned Instagram engagement is based on organic interactions relative to organic reach.

Competitor engagement is calculated differently because external reach is not available; follower-based comparison may be used instead.

Therefore:
- do not compare owned and competitor engagement rates as identical;
- do not infer competitor reach;
- preserve formula definitions.

## 2026 broad benchmark context

Metricool's 2026 Instagram study reports:
- strong Reel discovery/interaction behavior;
- strong carousel save behavior;
- increased saturation and declining broad reach in prior-period comparisons;
- a strong warning that posting more is not enough.

These are contextual priors, not Polo Connect targets.

## First-party priority

When Polo Connect has sufficient first-party samples:
- prefer Polo Connect baselines;
- use external studies only for hypothesis generation and contextual interpretation.

## API changes

Instagram/Meta metrics can be renamed, deprecated, or redefined.

When a definition changes:
1. record change date;
2. version the metric;
3. stop seamless historical comparison;
4. create a new baseline when necessary.
