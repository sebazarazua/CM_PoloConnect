# Measurement framework

## Objective-first measurement

Every content item should have:
- primary objective;
- primary KPI;
- diagnostic metrics;
- guardrail metrics.

## Example mappings

### Reach
Primary candidates:
- organic reach;
- non-follower reach;
- discovery views.

Diagnostics:
- shares;
- profile visits;
- follows.

### Engagement / interaction
Primary candidates:
- relevant interaction rate;
- shares per reach;
- saves per reach;
- comments per reach.

Avoid using one generic engagement metric for every content type.

### Retention
Primary candidates:
- average watch time;
- retention/completion when available;
- Story continuation/exit behavior.

### Authority / utility
Primary candidates:
- saves;
- shares;
- repeat consumption;
- qualified comments/questions.

### Community
Primary candidates:
- meaningful comments;
- replies;
- Story participation;
- recurring participants.

### Event awareness
Primary candidates:
- reach among relevant audience;
- schedule saves/shares;
- profile/link actions.

### Live viewership
Primary:
- attributable match starts/viewers.

Diagnostics:
- link taps;
- landing sessions;
- Story actions;
- live-promo reach.

### Replay viewership
Primary:
- attributable replay starts.

### Product discovery
Primary:
- attributable feature/session entry.

### Sponsor delivery
Primary:
- contract-defined delivery metric.

Do not substitute an easier metric when contractual measurement exists.

## Metric classes

### Outcome
Closest to objective.

### Diagnostic
Helps explain outcome.

### Guardrail
Protects another important dimension.

### Context
Describes environment but is not a success metric.

## Reporting discipline

Lead with objective outcome, not the largest number available.
