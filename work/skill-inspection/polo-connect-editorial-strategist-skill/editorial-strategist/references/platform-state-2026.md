# Platform state — reviewed 2026-10-24

This file contains time-sensitive strategic priors, not permanent rules.

## Instagram 2026 working priors

Large 2026 benchmark datasets indicate:
- Reels remain strong for discovery and interaction;
- carousels are particularly strong for saves and structured/deeper consumption;
- Stories remain important for direct audience connection;
- single-image posts underperform broad averages relative to Reels/carousels, but remain valid when one image/message is the right editorial solution;
- much post performance concentrates in the first several days;
- sustainable cadence matters more than chasing one universal posting frequency.

## Human-content prior

Current social strategy research indicates that audiences value human-generated brand content and authentic participation. AI should increase insight and process efficiency rather than become the visible creative identity by default.

## Operational consequences

Do not encode:
- a universal post-per-week target;
- a universal format split;
- a universal posting hour;
- "Reels always win";
- "single images are forbidden".

Instead:
1. select format based on content job;
2. use generic benchmark data as a prior;
3. measure Polo Connect's own audience;
4. update strategy from repeated first-party evidence.

## Refresh triggers

Review this file when:
- Instagram changes recommendation/distribution behavior materially;
- metric definitions change;
- a new format becomes strategically material;
- 90 days pass and the guidance affects planning;
- Polo Connect's first-party evidence becomes strong enough to supersede generic benchmarks.
