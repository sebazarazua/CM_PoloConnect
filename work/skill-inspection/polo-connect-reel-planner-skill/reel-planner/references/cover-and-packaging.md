# Cover and packaging

## Cover purpose

The cover should communicate the Reel's identity in the grid/feed without misrepresenting the content.

## Cover options

### Hero frame
Strong authentic action/reaction frame with minimal branding.

### Result
Authentic frame + score/outcome.

### Character
Player/horse portrait or meaningful action frame.

### Context
Venue/event image + concise headline.

## Cover criteria

Evaluate:
- focal clarity;
- crop resilience;
- recognizable subject;
- information priority;
- brand consistency;
- feed readability.

## Avoid

- poster-style generative imagery unrelated to the video;
- too much text;
- tiny scoreboard data;
- misleading frame;
- excessive sponsor/logos;
- generic stock imagery;
- synthetic face/horse enhancement.

## Headline

Use a headline only if it adds context not obvious from the image.

Prefer specific:
- "EL GOL DEL TÍTULO"
over vague:
- "UNA NOCHE INOLVIDABLE"

when factually appropriate.

## Packaging fields

Plan:
- cover source frame;
- cover crop intent;
- headline;
- logo/brand treatment;
- sponsor treatment;
- feed/grid preview note.
