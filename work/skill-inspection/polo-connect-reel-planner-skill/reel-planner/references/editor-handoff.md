# Editor handoff

## Required brief

### Strategy
- opportunity ID;
- Reel job;
- primary objective;
- audience job;
- success signal.

### Narrative
- hook;
- architecture;
- target duration range;
- beat sheet.

### Footage
For each selected clip:
- source ID/path;
- in/out timecodes;
- role;
- must-use/optional;
- crop/framing notes;
- audio notes;
- rights state.

### Text
- overlay copy;
- score/stat/name text;
- appearance timing;
- hierarchy;
- subtitle transcript/source.

### Audio
- primary audio mode;
- source audio to preserve;
- commentary;
- music brief;
- rights state;
- mix priorities.

### Brand
- logo/bug;
- score package;
- sponsor obligations;
- visual constraints.

### Cover
- hero frame/timecode;
- headline;
- crop guidance;
- sponsor/brand treatment.

### Delivery
- preferred aspect;
- technical output check;
- target publish surface;
- deadline/value expiry;
- versioning requirements.

## Editor freedom

Editor may optimize:
- exact cut frame;
- micro pacing;
- transition technique;
- audio mix;
- color correction;
- subtitle line breaks;
- graphical timing.

Editor may not silently change:
- verified facts;
- score;
- identity;
- narrative objective;
- primary hook concept;
- rights status;
- sponsor obligations;
- core editorial angle.

## Replan triggers

Return to planning if:
- primary clip is unusable;
- rights change;
- fact changes;
- publication is delayed beyond relevance;
- new footage materially improves the story;
- sponsor/legal requirement changes narrative.
