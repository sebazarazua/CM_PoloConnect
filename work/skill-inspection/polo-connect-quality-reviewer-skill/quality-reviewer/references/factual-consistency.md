# Factual consistency

## Source-of-truth ledger

Preferred facts:
- event ID;
- claim ID;
- canonical entity IDs;
- verified score;
- date/time;
- quote ID;
- stat source;
- rights source;
- viewing destination.

## Cross-surface matrix

Check every material fact across:

- final visual;
- carousel slides;
- cover;
- Reel overlay;
- subtitles;
- caption;
- Story frames;
- alt text;
- CTA;
- metadata.

## Common failures

- score mismatch;
- team swap;
- wrong stage;
- old fixture time;
- wrong player image/name;
- quote truncation changes meaning;
- ranking without date;
- "live" after event ended;
- replay link not yet available;
- sponsor name from previous tournament;
- historical claim copied from old content.

## Superlatives

Words such as:
- first;
- only;
- best;
- biggest;
- historic;
- record;
- unbeaten;
- youngest;
- oldest;
- most;

are factual claims.

Require evidence.

## Visual implication

A misleading visual can create a false claim even when the text is technically correct.

Examples:
- player photo implies player scored;
- archive image presented as current;
- wrong horse paired with horse name;
- trophy image implies championship result.

Review visual semantics, not text only.

## Corrections

If an upstream fact changes:
- invalidate affected copy;
- invalidate affected design/video overlays;
- invalidate alt text;
- invalidate schedule metadata;
- rerun relevant QA.

Do not patch only the most visible field.
