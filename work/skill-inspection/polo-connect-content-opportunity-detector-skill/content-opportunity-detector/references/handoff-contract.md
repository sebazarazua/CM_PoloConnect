# Handoff contract

## Purpose

Ensure downstream production skills receive strategy that is already decided.

## Required handoff fields

### Decision
- decision state
- priority
- opportunity score
- timing class
- publish window
- expiry

### Strategy
- primary objective
- secondary objectives
- audience job
- editorial angle
- why now
- why Polo Connect

### Content direction
- preferred format
- fallback format
- expected duration/slide count only when useful
- key information hierarchy
- emotion or audience promise
- benchmark mechanisms if any

### Evidence
- source event IDs
- required facts
- uncertainty notes

### Assets
- required assets
- readiness
- rights state
- capture/data requirements

### Constraints
- brand constraints
- sponsor constraints
- legal/rights constraints
- avoid/repetition notes

### Measurement
- intended success signal
- secondary signal
- learning hypothesis

### Routing
Suggested downstream skill:
- `reel-planner`
- `social-designer`
- `copywriter`
- `story-producer`
- future equivalent

## No strategy drift

Downstream skills may optimize execution but should not silently change:
- the primary objective;
- audience job;
- verified facts;
- core editorial angle;
- rights constraints.

If production reveals a material problem, route back for re-evaluation rather than improvising a new strategy.
